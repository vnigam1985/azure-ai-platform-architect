# Certifications for Azure AI Platform Architects (2026)

Microsoft retired several exams in 2026. Older blog posts and videos will point you at exams that no longer exist. This list was checked on Microsoft Learn in October 2026. Microsoft Learn is the only source of truth for exam status.

## What changed in 2026

| Old exam | Status | Replacement |
| --- | --- | --- |
| AI-900 | Exam retired June 30, 2026 | **AI-901** (same Azure AI Fundamentals certification) |
| AI-102 | Retired June 30, 2026 | **AI-103** Azure AI Apps and Agents Developer Associate |
| AZ-500 | Retired August 31, 2026 | **SC-500** Cloud and AI Security Engineer Associate |

## Recommended path

| Order | Certification | Exam | Free prep |
| --- | --- | --- | --- |
| 1 (optional) | [Azure AI Fundamentals](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-fundamentals/) | AI-901 | Learning paths on the cert page |
| 2 | [Azure AI Apps and Agents Developer Associate](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-apps-and-agents-developer-associate/) | AI-103 | [AI-103T00 course](https://learn.microsoft.com/en-us/training/courses/ai-103t00), [John Savill study cram](https://www.youtube.com/watch?v=WK2BvjOYTCQ) |
| 3 | [Cloud and AI Security Engineer Associate](https://learn.microsoft.com/en-us/credentials/certifications/cloud-and-ai-security-engineer-associate/) | SC-500 | [SC-500T00 course](https://learn.microsoft.com/en-us/training/courses/sc-500t00) |
| 4 | [Azure Solutions Architect Expert](https://learn.microsoft.com/en-us/credentials/certifications/azure-solutions-architect/) | AZ-305 | Learning paths on the cert page |
| 5 | [Azure Network Engineer Associate](https://learn.microsoft.com/en-us/credentials/certifications/azure-network-engineer-associate/) | AZ-700 | Learning paths on the cert page |
| 6 | [Cybersecurity Architect Expert](https://learn.microsoft.com/en-us/credentials/certifications/cybersecurity-architect-expert/) | SC-100 | Learning paths on the cert page |
| 7 | [IAPP AIGP](https://iapp.org/certify/aigp/) | AIGP | Body of knowledge on the IAPP page |

If you already hold AZ-305 or AZ-700, keep them renewed (free online renewal assessment on Microsoft Learn each year) and focus on AI-103 and SC-500.
